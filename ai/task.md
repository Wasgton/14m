# task

Create a website for a event producer
The main type of events produced are Music festivals

# context

- The company is called 14M
- The company is based in Lauro de Freitas/Bahia/Brazil
- The company is a music events producer
- The company is called 14M because its the name of a group of 14 women created in a forró classroom, but not all the members of the group are part of the company now, they only keep the name.
- The first event produced was an event called "Forró de Responsa" you can google it to more context
- The company has a instagram account @14mproducoes
- Although the name is typed since beggining as 14M, the company now is using a lot KTORZE M, the images of the company also show KTORZE M and the logotype also, so its better to use KTORZE M as its the most used.
- The producer has events throught the year, so the website must be updated with the events, so it must have a section to show the events, with the name of the event, the date, the location, the description and the price of the tickets.

# requirements

- It must use VueJs
- It must use TailwindCSS
- It must use TypeScript
- It must be responsive
- It must be fast
- It must be SEO friendly
- It must be accessible
- It must be secure
- It must be scalable
- It must be maintainable
- It must be documented

# instructions 

- make it modern and elegant, but also energetic
- make a portfolio section/page
- social networks section with button links to instagram, facebook and twitter
- use smooth effects and animations
- The producer has a lot of photos and videos of the events, so the website must have a section to show the photos and videos of the events.
- The producer has a lot of partners, so the website must have a section to show the partners, with the name of the partner, the logo and the website.
- The producer has a lot of sponsors, so the website must have a section to show the sponsors, with the name of the sponsor, the logo and the website.
- The producer has a lot of artists, so the website must have a section to show the artists, with the name of the artist, the logo and the website.
